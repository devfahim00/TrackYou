# TrackYou

Simple expense tracker for Android (Kotlin + Jetpack Compose + Room).

- First launch: name + currency
- Income / expense tracking with categories
- Dena-Paona (money you owe / money owed to you) with partial payments
- Savings goals with deposit / withdraw
- Package: `com.devfahim00.trackyou`

Debug APK is built by GitHub Actions and published under **Releases -> debug-latest**.
